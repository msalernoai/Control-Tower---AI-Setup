## What it really is
(Example guide.) A skill is a folder in `~/.claude/skills/<name>/` with a `SKILL.md`. Its `description`
is what Claude reads to decide when to use it.

## Status
Built into Claude Code. Checked on 2026-10-19.

## Do you already have it?
This repo ships three: `brain`, `reflect`, `humanizer`.

## Step by step to try it
1. Pick a task you repeat every week.
2. Write the steps you explain to Claude every time into `~/.claude/skills/<name>/SKILL.md`.
3. Start a new session and ask for the task in your own words. (30 min)

## Traps and hype
A vague description means the skill never fires. Too many skills cost context in every session.
